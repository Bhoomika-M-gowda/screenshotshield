## Where it succeeds
- **Pasted/regenerated image areas** (sample 03): ELA and noise agree, text-layout adds a hint, so the region is ranked #1 with *medium* confidence and the correct coordinates.
- **No false alarms** on a clean JPEG (01), a PNG without EXIF (05, ELA marked *unavailable*, not suspicious) or a heavily re-compressed genuine file (04: ELA down-weighted, no region reaches medium confidence).
- **Metadata** editor tags are reported (tested in the unit tests); missing EXIF is always "inconclusive".

## Where it fails (be honest in the demo)
- **False negatives:** samples 02 and 06 (text retyped, then the whole image re-saved at a *higher* quality) are scored Low. The edit leaves almost no pixel-level trace once the file is re-saved, and ELA at one quality cannot see it. In 06 the Photoshop tag alone raises only the 10-point metadata component, which is intentional: a tag is not proof.
- **Partial:** sample 02b (spliced crop with different compression) is highlighted by the noise check at the right place, but only at *low* confidence, so the overall score stays Low.
- **Recurring false positive region:** a low-confidence "noise" box often appears around the bold right-aligned value text in the first detail row (e.g. "Ravi Kumar Stores"). It never raises a category by itself, but a reviewer will see it.
- Heavily compressed images reduce the reliability of every pixel-level signal; the engine caps ELA at 0.4 for low-quality JPEGs, but other signals can still be noisy.
- Thresholds were tuned on this small synthetic set, so these numbers show behaviour, **not accuracy on real-world data**. No statistical validation has been performed.
